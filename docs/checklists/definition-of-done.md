# Checklist — Definition Of Done

## Obrigatório

- [ ] Escopo da tarefa está claro e limitado.
- [ ] Mudanças feitas em diffs pequenos e focados.
- [ ] Gate canônico de `AGENTS.md` executado com sucesso.
- [ ] Testes criados/atualizados para comportamento alterado.
- [ ] Sem lógica de domínio em UI.
- [ ] Sem quebra de contrato público sem plano de migração.

## Se houve mudança estrutural

- [ ] ADR criada/atualizada em `docs/adr/`.
- [ ] `docs/architecture.md` atualizado.
- [ ] Registro de consistência/auditoria atualizado, quando aplicável.
