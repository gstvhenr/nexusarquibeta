# Default Task Flow (.agent)

1. Read `AGENTS.md`, `NEXT.md`, `ARCHITECTURE.md`.
2. Run baseline using commands defined in `AGENTS.md`.
3. Update `PLAN.md` with scope, out-of-scope, risks, binary criteria.
4. Implement in small diff (1 behavior per change).
5. Run canonical gates from `AGENTS.md`.
6. Self-review using `.agent/checklists/self-review-agent.md`.
7. Update `NEXT.md` and decisions/ADR if structural.
8. Register evidence (executed commands + objective results).
